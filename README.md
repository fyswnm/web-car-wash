# 🚗 极限洗车大亨 (Car Wash Master)

一款专为 **iPad / iPhone / 桌面端 Chrome** 优化的高画质交互式 Web 网页洗车游戏。

---

## 🌟 核心功能特色

1. **多端原生级触控与鼠标交互**：
   - 适配 iPad、iPhone 视口与刘海屏安全区（`safe-area-inset`），支持手指触控滑动与鼠标点击拖拽洗车。
   - 开启 `touch-action: none` 与 `overscroll-behavior: none`，洗车滑动时屏幕不晃动、不橡皮筋回弹。
   - 支持多分辨率 Retina 屏幕自适应渲染（`devicePixelRatio`）。

2. **3分钟倒计时与洗车进度实时统计**：
   - 车辆干净度由初始污渍与残余健康度实时计算（0% ~ 100%）。
   - 达到 100% 时自动通关结算。
   - 严格 3 分钟限时（180秒），剩余 30 秒时触发紧急警报音效与跳动视觉警告；超时后自动停止并评级。

3. **脏污程度调节（轻微脏 / 一般脏 / 很脏）**：
   - **轻微脏**：日常微尘泥点，快速清洗即可完工。
   - **一般脏**：常见雨水污渍与局部污块。
   - **很脏**：污渍密集且**顽固度大幅增加（2.4倍耐磨度）**，玩家需要在每个污点上多喷洗、多冲刷、多擦拭一会才能彻底洗净！
   - 真实多维污渍系统：
     - 🟤 **泥土脏 (Mud)**：车底与轮拱厚泥，水枪高压冲刷效果绝佳。
     - 🌫️ **灰尘脏 (Dust)**：全车哑光积灰，超细纤维洗车布擦拭抛光效果最佳。
     - 🥫 **番茄酱 (Ketchup)**：黏性高附着污点，需先喷泡沫浸泡软化。
     - 💩 **鸟粪/大便 (Poop)**：顽固坚硬污渍，耐磨度最高，需泡沫软化+强力水枪交替击碎！

## 🚀 启动与体验方式

直接在浏览器中打开 `index.html`，或启动本地静态服务器：

```bash
# 方式 1：Python 一键启动
python3 -m http.server 8080

# 访问地址：
# 本机 Chrome: http://localhost:8080
# 同局域网 iPhone / iPad: http://<你的电脑内网IP>:8080
```

## 🛠️ 后续添加新车或新颜色的接口说明

代码采用模块化解耦设计，新车和新颜色全部集中在 `js/config.js` 的 `CarRegistry` 注册器中。

### 添加新车示例：
只需在 `js/config.js` 中调用 `CarRegistry.register({ ... })`：

```javascript
CarRegistry.register({
  id: 'porsche_911',
  name: '保时捷 911',
  brand: 'Porsche',
  type: 'supercar',
  badge: '经典蛙眼',
  description: '后置后驱跑车代表作，标志性飞线轮廓。',
  colors: [
    { id: 'shark_blue', name: '鲨蓝', hex: '#0083ca', secondaryHex: '#005a8c', finish: 'gloss' },
    { id: 'guards_red', name: '卫红', hex: '#d5001c', secondaryHex: '#9b0014', finish: 'gloss' },
    { id: 'crayon_gray', name: '蜡灰', hex: '#b2b3ae', secondaryHex: '#7f817d', finish: 'metallic' }
  ]
});
```
车辆选择弹窗与切换系统将**全自动生成新车卡片与对应的色块选项**，无需修改任何 DOM 结构！
